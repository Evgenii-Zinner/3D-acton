> *«Здраствуйте. Я, Кирилл. Хотел бы чтобы вы сделали игру, 3Д-экшон суть такова…  
> Пользователь может играть лесными эльфами, охраной дворца и злодеем.  
> И если пользователь играет эльфами то эльфы в лесу, домики деревяные набигают солдаты дворца и злодеи.

> — **Кирилл**, легендарный классик Рунета (ок. 2003 г.)

## 🧐 Что это такое? / What on Earth is this?

### Русский
В начале 2000-х на форумах Absolute Games (ag.ru) и GameDev.ru появилось письмо от пользователя по имени **Кирилл**, который умолял разработчиков создать «3Д-экшон» его мечты. Из-за неповторимой орфографии, детской искренности и идеального геймдизайнерского вижена письмо моментально стало главным святым граалем и мемом русскоязычного интернета.

Фразы **«корованы»**, **«набигают»**, **«домики деревяные»** и **«джва года ждал»** вошли в культурный код целого поколения разработчиков и геймеров. Десятки студий годами вставляли отсылки на корованы в свои релизы, но полноценной игры по оригинальному ТЗ так и не выходило.

**Спустя джвадцать лет ожидания свершилось:**  
Мы скормили канонический текст Кирилла без изменений в **Google AI Studio** ([aistudio.google.com](https://aistudio.google.com)), и нейросеть сгенерировала полноценный 3D-экшон на **React + Three.js** с полным соблюдением всех пунктов письма!

### English
In the early 2000s on Russian gaming forums, a user named **Kirill** posted an infamous, hilariously misspelled pitch for his dream video game: a *3D action game* featuring wood elves in wooden houses, palace guards, a villain, dense forests, soldiers raiding the huts, and most importantly: **the ability to rob caravans** (*"грабить корованы"*), a game he had been waiting *"two [джва] years for"*.

It became the #1 legendary gaming meme in the Russian-speaking web. Over 20 years later, we fed the exact original Russian prompt into **Google AI Studio** ([aistudio.google.com](https://aistudio.google.com)) — and it actually built the entire working 3D game in WebGL / Three.js!

## 🎮 Игровой процесс / Features

Все требования Кирилла воплощены на 100%:

1. **3 играбельные фракции (в любой момент можно сменить в меню):**
   - 🧝 **Лесные Эльфы:** Живут в густом лесу в деревянных домиках. Вооружены Эльфийским Луком Ветров. Защищают поселение от набегов и устраивают засады на купеческие корованы.
     - *Способности:* Тройной залп стрел (`Q`), Лесной рывок (`E`), Гнев древней чащи (`R`).
   - 🛡️ **Охрана Дворца:** Тяжёлые королевские латники с алебардами. Охраняют повозки с казной и периодически набигают на лесные домики ради наведения порядка.
     - *Способности:* Круговой рассек алебардой (`Q`), Таран щитом (`E`), Королевский горн с арбалетным залпом (`R`).
   - 🦹 **Главный Злодей:** Тёмный владыка в капюшоне. Набигает на эльфийские домики, штурмует охрану дворца и грабит корованы ради золота и хаоса.
     - *Способности:* Огненный череп (`Q`), Теневой скачок-телепорт (`E`), Метеоритный дождь (`R`).

2. **🐪 МОЖНО ГРАБИТЬ КОРОВАНЫ:**
   - По дорогам между Дворцом и Цитаделью следует корован — повозка с золотом в сопровождении охраны.
   - Разбейте повозку, чтобы из неё посыпались монеты и эликсиры!
   - Кнопка *«Отправить корован!»* позволяет вызывать новые корованы в любой момент.

3. **🏚️ Домики деревяные и набеги:**
   - В центре карты расположена деревня с деревянными домиками.
   - Таймер отсчитывает время до следующего набега: отряды солдат и миньонов **набигают** на домики.
   - Кнопка *«Набежать!»* позволяет спровоцировать набег немедленно.

4. **🌲 Густой лес и тп…:**
   - Процедурный 3D-мир на Three.js: высокие дубы и ели, колышущаяся трава, дворец на северо-востоке, мрачная цитадель злодея на юго-западе.

5. **📜 Интерактивная «Энциклопедия Кирилла»:**
   - Встроенный свиток с оригинальным письмом, счётчиками ограбленных корованов и толкованием канонических мемов.

## 🕹️ Управление / Controls

| Клавиша / Ввод | Действие |
|---|---|
| **W, A, S, D** / Стрелочки | Перемещение персонажа |
| **Пробел** | Прыжок |
| **Мышь (движение)** | Вращение камеры от третьего лица |
| **ЛКМ (Левая кнопка)** | Основная атака (выстрел из лука / удар алебардой / сгусток тьмы) |
| **ПКМ (Правая кнопка)** | Зажать для ручного вращения камеры |
| **Q** | Первая способность (AoE / Залп / Рассек) |
| **E** | Рывок / Уклонение / Телепорт |
| **R** | Ультимативная способность (Метеориты / Горн / Корни) |
| **M** | Переключение звука / Mute |

## 🛠️ Стек технологий / Tech Stack

- **Движок & Графика:** [Three.js](https://threejs.org/) (3D рендеринг, освещение, процедурные меши, частицы)
- **UI & Состояние:** [React 19](https://react.dev/), [Tailwind CSS 4](https://tailwindcss.com/)
- **Иконки & Анимации:** [Lucide React](https://lucide.dev/), [Motion](https://motion.dev/), [Canvas-Confetti](https://github.com/catdad/canvas-confetti)
- **Звук:** Web Audio API (синтез звуков в реальном времени без внешних тяжелых mp3)
- **Сборщик:** [Vite 8](https://vite.dev/)
- **Сервер / Edge адаптер:** [Cloudflare Workers](https://workers.cloudflare.com/) (Workers Static Assets)

## 🚀 Запуск локально / Local Development

Проект оптимизирован для работы как с **Bun**, так и с **Node.js** (npm / pnpm / yarn):

```bash
# 1. Клонировать репозиторий
git clone https://github.com/<your-username>/3D-acton.git
cd 3D-acton

# 2. Установить зависимости
bun install
# или: npm install

# 3. Запустить локальный сервер разработки
bun run dev
# или: npm run dev
```

Откройте в браузере: `http://localhost:3000`

## ☁️ Деплой в Cloudflare Workers

В репозитории уже настроен готовый адаптер для мгновенного развёртывания в **Cloudflare Workers** через modern Workers Static Assets.

### Структура адаптера:
- [`wrangler.jsonc`](./wrangler.jsonc) — конфигурация Cloudflare Workers с привязкой статических ассетов (`ASSETS`) и SPA-маршрутизацией.
- [`worker/index.ts`](./worker/index.ts) — TypeScript Worker, обслуживающий статику с кэширующими заголовками и секретным пасхальным API-эндпоинтом `/api/lore`.

### Инструкция по деплою:

1. **Авторизуйтесь в Cloudflare CLI:**
   ```bash
   bun x wrangler login
   # или: npx wrangler login
   ```

2. **(Опционально) Проверьте локально в эмуляторе Workers:**
   ```bash
   bun run preview:cf
   # или: npm run preview:cf
   ```

3. **Сделайте сборку и деплой одной командой:**
   ```bash
   bun run deploy:cf
   # или: npm run deploy:cf
   ```

Wrangler соберет Vite-бандл в папку `dist/`, загрузит статические ассеты на глобальную edge-сеть Cloudflare и выдаст вам публичный URL вида:
```
https://three-d-acton.<your-subdomain>.workers.dev
```

### Пасхальный API в Cloudflare Worker:
После развёртывания доступен эндпоинт:
- `GET /api/lore` (или `/api/meme`) — возвращает канонический манифест Кирилла в формате JSON с заголовками `x-djva-goda: fulfilled`.

## 📦 Деплой на GitHub Pages

Если вы хотите хостить игру прямо на GitHub Pages:
1. В `vite.config.ts` укажите `base: './'`.
2. Запустите `bun run build` (или настройте GitHub Actions Workflow для `vite build` и деплоя папки `dist/`).
